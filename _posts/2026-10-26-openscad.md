# Moving to OpenSCAD : Why I Left Freecad

## 1. Why I left Freecad?
On October 26, 2026, I was planning to make something that is related to aerospace engineering (My favorite topic).
And just tried to make some model rocket with **Freecad**. 
I struggled to create the nosecone using a B-spline in Freecad. 
After spending about 2 hours troubleshooting,
I decided to find something else.

## 2. Why OpenSCAD?
At this point, you might wonder why I am not using **Fusion360**, **Inventor**.
Well, I couldn't use them on my Linux setup.
As you know, Autodesk's software doesn't support Linux.
So, I found something else :
- Onshape
- OpenSCAD

Onshape was a great choice, But I wanted to work at my Local environment.
Therefore, I chose OpenSCAD.


## 3. What is OpenSCAD
According to OpenSCAD's website,
> OpenSCAD is not an interactive modeller. Instead It is something like a 3D-compiler that reads in a script file that describes the object
> and renders the 3D model from this script file.

It means, It is not a general modeller like blender,fusion360,inventor,thinkercad.
It requires a script file to make 3D object. (It's cool)
> Code --> 3D object
